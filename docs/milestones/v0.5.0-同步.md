## 产品边界

**本阶段做什么：**
- Git 同步：`~/.devboard/` 自动 commit/push
- WebDAV 同步：Nextcloud 等 WebDAV 服务器同步
- Syncthing / SSH 等其他同步方式

**本阶段不做什么：**
- 不做实时协同编辑
- 不做冲突自动合并
- 不做云端数据库

## 子任务详细设计

### 1 Git 同步

- **功能目标**：将 `~/.devboard/` 目录纳入 Git 管理，支持自动 commit/push
- **文件结构**：新建 `src/sync/git.rs`、`src/cli/sync.rs`
- **接口设计**：
  - CLI：`devboard sync git init` / `devboard sync git push` / `devboard sync git pull` / `devboard sync git status`
  - 自动 commit：每次重要操作后自动 commit（可配置开关）
- **后端流程**：初始化 Git 仓库 → 检测变更 → 自动 commit → push 到远端
- **测试标准**：初始化、push、pull、status
- **提交信息**：`feat: add Git sync`

### 2 WebDAV 同步

- **功能目标**：支持通过 WebDAV 协议同步数据到 Nextcloud 等服务器
- **文件结构**：新建 `src/sync/webdav.rs`
- **接口设计**：
  - CLI：`devboard sync webdav init --url <url> --user <user>` / `devboard sync webdav push` / `devboard sync webdav pull`
  - 配置存储在 `~/.devboard/config.toml`
- **后端流程**：WebDAV 上传/下载 → 冲突检测 → 数据合并
- **测试标准**：配置、push、pull
- **提交信息**：`feat: add WebDAV sync`

### 3 Syncthing/SSH 同步

- **功能目标**：支持通过 Syncthing 或 SSH 同步数据
- **文件结构**：新建 `src/sync/external.rs`
- **接口设计**：
  - CLI：`devboard sync external status` / `devboard sync external start`
  - 配置：指定同步目录或 SSH 地址
- **后端流程**：监控目录变更 → 同步到目标
- **测试标准**：状态查询、同步启动
- **提交信息**：`feat: add external sync (Syncthing/SSH)`
