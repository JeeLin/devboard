# 功能验收：v0.1.0

## 验收范围

里程碑 v0.1.0 定义的功能：
- 项目、里程碑、任务的 CRUD 操作
- 三种任务类型（Requirement / Task / Bug）
- 状态流转（待办→进行中→评审→完成）
- SQLite 数据层和 schema 迁移
- CLI 基础命令

## 验证方法

1. 检查代码实现是否符合里程碑文档中的子任务详细设计
2. 运行单元测试验证数据模型和数据库层
3. 手动测试 CLI 命令基本功能

## 验证结果

- 数据模型：Project、Milestone、Task、TimeEntry 结构体正确定义，并能够从数据库行中读取
- 数据库层：连接、迁移、CRUD 操作正常工作
- CLI：所有子命令（project、milestone、task）可用，参数解析正确
- 功能：能够创建项目、里程碑、任务；能够更新任务状态；能够列出任务并按类型/状态筛选
