# v0.3.0: 完整

## Context
v0.2.0 好用阶段已完成，实现了时间追踪功能和看板视图。v0.3.0 将在此基础上添加文档系统、全文搜索、子任务、周/月报表和丰富的图表功能，使工具更加完整。
版本类型：minor（新功能）
里程碑起始 ref: 7cc312677cc92497b120b1deb67c2441fda7b49c

## 产品边界
本阶段做什么：
- Markdown 文档系统（任务扩展上下文）
- 文档看板视图（草稿→评审→发布→归档）
- 全文搜索（SQLite FTS5）
- 子任务支持
- 周/月工时报表
- 图表功能（甘特图、燃尽图、工时分布、任务状态、里程碑进度、AI vs 人贡献）

本阶段不做什么：
- 标签系统（v0.4）
- 文档关联任务（v0.4）
- 同步功能（v0.5）
- 高级导出功能（v0.4）

## 子任务详细设计

### 1 Markdown 文档系统：支持任务关联文档

- **功能目标**：支持任务关联 Markdown 文档，扩展任务上下文
- **文件结构**：
  - `src/models/document.rs`：文档数据模型
  - `src/db/migration.rs`：添加文档相关表
- **接口设计**：
  ```bash
  devboard doc add --task <task_id> --title "标题" --file <path>
  devboard doc list --task <task_id>
  devboard doc get <doc_id>
  ```
- **后端流程**：CLI → 文档模型 → 数据库存储
- **测试标准**：`cargo test` 中的文档相关测试通过
- **提交信息**：`feat: add document system for task context`

### 2 文档看板视图：草稿→评审→发布→归档

- **功能目标**：在 TUI 中实现文档看板视图，按文档状态分类展示
- **文件结构**：
  - `src/tui/doc_kanban.rs`：文档看板视图
  - `src/tui/app.rs`：扩展 TUI 支持文档看板
- **接口设计**：
  - 使用 F 键切换到文档看板视图
  - 支持通过箭头键在文档卡片间导航
- **后端流程**：TUI → 核心逻辑层获取文档数据 → 渲染文档看板视图
- **测试标准**：TUI 能够启动并显示文档看板视图（手动验证）
- **提交信息**：`feat: add document kanban view to TUI`

### 3 全文搜索：基于 SQLite FTS5

- **功能目标**：支持对任务和文档进行全文搜索
- **文件结构**：
  - `src/models/search.rs`：搜索功能实现
  - `src/db/migration.rs`：添加 FTS5 虚拟表
- **接口设计**：
  ```bash
  devboard search <query>  # 全文搜索
  ```
- **后端流程**：CLI → FTS5 索引 → 返回匹配结果
- **测试标准**：搜索功能准确，性能可接受
- **提交信息**：`feat: add full-text search with SQLite FTS5`

### 4 子任务支持：任务拆分和层级关系

- **功能目标**：支持任务拆分为子任务，维护层级关系
- **文件结构**：
  - `src/models/task.rs`：扩展任务模型支持子任务
  - `src/db/migration.rs`：任务表已支持 parent_id
- **接口设计**：
  ```bash
  devboard task add --parent <task_id> --title "子任务标题"
  devboard task list --parent <task_id>  # 列出子任务
  ```
- **后端流程**：CLI → 任务模型 → 数据库存储
- **测试标准**：子任务 CRUD 操作正常，层级关系正确
- **提交信息**：`feat: add subtask support with hierarchy`

### 5 周/月工时报表

- **功能目标**：提供按周/月统计的工时报表
- **文件结构**：
  - `src/cli/time.rs`：扩展报表命令
  - `src/models/time_entry.rs`：添加周/月查询函数
- **接口设计**：
  ```bash
  devboard time report --week          # 本周报表
  devboard time report --month         # 本月报表
  devboard time report --week --date 2024-01-15  # 指定周报表
  ```
- **后端流程**：CLI → 查询时间聚合 → 格式化输出
- **测试标准**：报表数据准确，格式清晰易读
- **提交信息**：`feat: add weekly and monthly time reports`

### 6 图表功能：甘特图、燃尽图、工时分布等

- **功能目标**：提供多种图表可视化项目状态
- **文件结构**：
  - `src/charts/`：图表生成模块
  - `src/charts/gantt.rs`：甘特图
  - `src/charts/burndown.rs`：燃尽图
  - `src/charts/distribution.rs`：工时分布图
- **接口设计**：
  ```bash
  devboard chart gantt --milestone <id>       # 甘特图
  devboard chart burndown --milestone <id>    # 燃尽图
  devboard chart distribution --date <date>   # 工时分布图
  ```
- **后端流程**：CLI → 数据聚合 → 图表生成（SVG/PNG）
- **测试标准**：图表生成正确，输出格式正确
- **提交信息**：`feat: add chart generation (gantt, burndown, distribution)`
