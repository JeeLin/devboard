# v0.4.0: 增强

## Context
v0.3.0（完整）已实现 Markdown 文档系统、全文搜索、子任务支持、周/月报表、图表功能。v0.4.0 聚焦于增强开发体验：标签分类、文档与任务的双向关联、快速笔记、任务模板复用、图表批量导出。

版本类型：minor（新功能）
里程碑起始 ref: 5658b96c09bff79335c2fa5c2c86237419e2e1b7

## 产品边界

**本阶段做什么：**
- 标签系统：给任务/文档打标签，按标签过滤
- 文档关联任务：双向关联，支持从任务查文档、从文档查任务
- 快速笔记：一键创建临时笔记，自动按日期归档
- 任务模板：预定义模板快速创建任务
- 图表批量导出：CSV / SVG / PNG 批量导出

**本阶段不做什么：**
- 不做同步功能（v0.5）
- 不做 TUI 界面扩展
- 不做多人协同

## 子任务详细设计

### 1 标签系统

- **功能目标**：任务和文档支持标签分类，可按标签过滤
- **文件结构**：新建 `src/models/tag.rs`，修改 `src/db/migration.rs`、`src/cli/tag.rs`
- **接口设计**：
  - 表：`tags(id, name, color)` 和 `task_tags(task_id, tag_id)` / `document_tags(document_id, tag_id)`
  - CLI：`devboard tag add <name>` / `devboard tag list` / `devboard task tag <task_id> --add <tag>` / `devboard task list --tag <tag>`
- **后端流程**：创建标签 → 关联到任务/文档 → 过滤查询
- **测试标准**：标签 CRUD、关联/取消关联、按标签过滤
- **提交信息**：`feat: add tag system`

### 2 文档关联任务

- **功能目标**：文档与任务双向关联，支持双向查询
- **文件结构**：修改 `src/models/document.rs`、`src/cli/doc.rs`
- **接口设计**：
  - 表：`document_links(document_id, task_id)`（已存在，复用）
  - CLI：`devboard doc link <doc_id> --task <task_id>` / `devboard doc unlink <doc_id> --task <task_id>` / `devboard doc list --task <task_id>` / `devboard task docs <task_id>`
- **后端流程**：关联/取消关联 → 双向查询
- **测试标准**：关联/取消关联、双向查询、去重
- **提交信息**：`feat: add document-task linkage`

### 3 快速笔记

- **功能目标**：一键创建临时笔记，自动按日期归档
- **文件结构**：新建 `src/cli/note.rs`
- **接口设计**：
  - CLI：`devboard note add "内容"` / `devboard note list [--date YYYY-MM-DD]` / `devboard note today`
  - 存储：`~/.devboard/notes/YYYY-MM-DD.md`（追加模式）
- **后端流程**：创建笔记文件 → 追加内容 → 列出笔记
- **测试标准**：创建笔记、按日期列出、今日笔记
- **提交信息**：`feat: add quick notes`

### 4 任务模板

- **功能目标**：预定义模板快速创建任务，减少重复输入
- **文件结构**：新建 `src/models/template.rs`、`src/cli/template.rs`
- **接口设计**：
  - 表：`task_templates(id, name, task_type, title_template, description_template, default_priority, default_actor)`
  - CLI：`devboard template add <name>` / `devboard template list` / `devboard task from-template <template_id> --project <id>`
- **后端流程**：创建模板 → 从模板创建任务 → 填充变量
- **测试标准**：模板 CRUD、从模板创建任务
- **提交信息**：`feat: add task templates`

### 5 图表批量导出

- **功能目标**：支持图表批量导出为 CSV / SVG / PNG 格式
- **文件结构**：修改 `src/charts/` 下模块
- **接口设计**：
  - CLI：`devboard chart export --type gantt --format svg --output output.svg` / `devboard chart export --all --format png --dir ./charts/`
  - 支持格式：svg（默认）、png、csv
  - 支持导出全部图表或指定类型
- **后端流程**：生成图表 → 格式转换 → 写入文件
- **测试标准**：单图导出、批量导出、格式正确性
- **提交信息**：`feat: add chart batch export`
